GET/health Vérifie que l'API et la base vectorielle sont opérationnels.

GET/project/{project_id}/stats Nombre de chunks indexés pour un projet donné.

POST/learn-from-code Analyse le code source du projet Symfony et l'indexe dans pgvector.

DELETE/project/{project_id} Supprime définitivement tous les chunks d'un projet de la base vectorielle.

POST/generate-test Génère un WebTestCase Symfony pour une route ou un controller.

POST/generate-unit-test Génère un test unitaire PHPUnit pour une classe ou méthode spécifique.

POST/generate-tests-batch Génère plusieurs tests fonctionnels en parallèle en mode asynchrone.

Un job asynchrone par classe. Récupérez les job_id et sondez /job/{id}/status.

GET/job/{job_id}/status Consulte l'état d'un job asynchrone (pending / running / done / error).

POST/admin/reset-schema Supprime et recrée toutes les tables. Toutes les données sont perdues.

Attention : cette action est irréversible. Tous les projets indexés seront supprimés.
